How this page works Use the form below to draft a new update — it renders live underneath so you can see it styled before it's real.
  1. Fill in the version, date, headpoints (one per line), and any screenshot URLs.
  2. Click Add to changelog to preview it.
  3. Click Export code and copy the block it gives you.
  4. Paste that block into the CHANGELOG_ENTRIES array near the top of this file's <script>, then re-upload the file to your host. That's what makes an entry permanent for everyone else visiting the page — entries added through the form only live in your browser until you do this.
