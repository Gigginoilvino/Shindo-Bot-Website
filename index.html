Governs your use of Spawn Alert Bot ("the Bot") on Discord. By adding the Bot to a server, or by using its commands, you agree to these terms on behalf of yourself and, if you're a server admin, on behalf of that server.

Adding the Bot to a Discord server, or interacting with any of its commands, means the server owner/admin who added it and each user who runs a command accept these Terms and the accompanying Privacy Policy in full. If you don't agree, remove the Bot from your server and stop using its commands.

2.What the bot does

The Bot tracks item spawn timers for the game Shindo Life and posts automated alerts in a channel you designate, along with related utility commands (subscriptions, private-server code lookups, boss-drop reporting, and similar). It is provided free of charge, as a convenience tool, with no guarantee of accuracy, uptime, or continued availability.

3.Who can use it

You must meet Discord's own minimum age requirement (currently 13, or higher where required by local law) and be permitted to use Discord under its Terms of Service. 5.What the bot will never do

Commitment to server safety This is a standing, non-negotiable limit on the Bot's design — not a feature that can be toggled on later, by request or otherwise.

The Bot will never include, and its operators will never add, any feature that:

Privacy Policy

Document 2

Explains what data Spawn Alert Bot collects, why, and what you can do about it.

1.What we collect

The Bot does not request Discord's Message Content, Presence, or Server Members privileged intents, and does not read your chat messages. It stores only what its features need to function:

  • Discord IDs — your user ID (for subscriptions and admin checks) and server/channel IDs (for routing alerts);
  • Command inputs — the item you subscribed to, a submitted server code, a boss-drop report you post, or an event toggle you set;
  • Per-server configuration — alert channel, drop channel, local admin roles, event flags, and similar settings a server admin configures.

We don't collect your email, IP address, payment information, or anything beyond what Discord's own API exposes for the interactions above.

2.How it's used

Data is used strictly to run the features you or your server admin turned on: sending you a subscribed-item ping, posting alerts in the configured channel, showing private-server codes for the right village, and enforcing who can run admin commands. It is not used for advertising, profiling, or any purpose outside operating the Bot.

3.Sharing & Discord

We don't sell or share your data with third parties. Because the Bot runs on Discord's platform, the data it processes is necessarily also visible to Discord Inc. under its own Privacy Policy. Server codes and drop reports you submit through commands are visible to other members of that server by design — don't post anything there you wouldn't want the server to see.

4.Retention & deletion

Subscription and configuration data is kept for as long as you remain subscribed, or the server keeps the Bot installed. Removing the Bot from a server deletes that server's configuration on its next data cleanup cycle. You can ask to have your personal data (e.g. your subscriptions) deleted at any time by contacting leon.nucera@gmail.com or by unsubscribing yourself via /unsubscribe.

5.Security

Data is stored in the Bot's own configuration files on infrastructure controlled by its operators. We take reasonable steps to keep this data restricted to the Bot's operators, but — as with any small, independently run service — we can't guarantee absolute security, and you should not treat anything submitted through the Bot's commands as confidential.

6.Your rights

You can view your own subscriptions with /mysubs, remove them with /unsubscribe, and request a copy or deletion of any data tied to your Discord ID by contacting leon.nucera@gmail.com. Server admins can remove server-level data (codes, channel settings) directly via the Bot's admin commands, or by removing the Bot.

7.Children's privacy

The Bot follows Discord's own minimum age policy (currently 13+) and does not knowingly collect data from users below that age beyond what Discord's platform itself already requires for account creation.
